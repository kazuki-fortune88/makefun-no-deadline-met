A program that writes one single-line joke giving an excuse for missing a
deadline, for the [make.fun bounty "One Line, No Deadline Met"](https://make.fun/bounty/u-markk-st-one-line-no-deadline-met-6adc00ce).

Built with referral `4fxhr3y1`.

## The line

> I missed the deadline because my to-do list unionized and went on strike the moment I opened it.

## Run

```sh
python3 main.py
```

This writes the joke to `/output/entry.txt` (or
`$MAKEFUN_OUTPUT_DIR/entry.txt` when that variable is set). The file is one
line, 96 characters, well under the 200-character cap.
